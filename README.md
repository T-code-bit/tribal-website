# Tribal Tech Website

## Project Overview
A cutting-edge, cyberpunk-inspired technology website showcasing innovative digital solutions.

## Key Features
- Responsive, dynamic hero section
- Particle network background
- Glitch text scramble effect
- Cyberpunk-inspired design

## Hosting Instructions
1. Ensure all files are in the root directory
2. Use a static site hosting service like:
   - GitHub Pages
   - Netlify
   - Vercel

## Dependencies
- No backend required
- Pure HTML, CSS, JavaScript
- Google Fonts (Orbitron, Roboto Mono)

## Browser Compatibility
Tested on modern browsers (Chrome, Firefox, Safari, Edge)

## Performance Notes
- Particle network may impact performance on older devices
- Recommended to test on various screen sizes

## Deployment Checklist
- [ ] Validate HTML
- [ ] Minify CSS and JS (optional)
- [ ] Test responsiveness
- [ ] Check cross-browser compatibility
